# Third-Party Data Attribution

This project uses flight data and aircraft metadata provided by
[The OpenSky Network](https://opensky-network.org/), a non-profit association,
accessed via Trino (`pyopensky`) and the OpenSky Aircraft Database.

## Required citation

Per the OpenSky Network General Terms of Use & Data License Agreement
(Section 4.i), any publication (including web pages) using this data must
cite:

> Bringing up OpenSky: A large-scale ADS-B sensor network for research
> Matthias Schäfer, Martin Strohmeier, Vincent Lenders, Ivan Martinovic, Matthias Wilhelm
> ACM/IEEE International Conference on Information Processing in Sensor Networks, April 2014

Website reference:

> The OpenSky Network, http://www.opensky-network.org

## License scope

Access to OpenSky Network data is granted solely for **non-profit research
and non-profit education** (Section 1 of the Agreement). This project is a
personal, non-commercial learning exercise and does not redistribute any raw
OpenSky data set — all fetched/cached data stays local to the machine running
it and is never committed to this repository or shared with third parties,
per Section 3(iii) of the Agreement.

## Aircraft database

Aircraft type/registration data is downloaded from the
[OpenSky Aircraft Database](https://opensky-network.org/data/aircraft),
provided "as is", unlicensed, with no support or guarantees of any kind.
